Importer depuis LinkedIn

Comment récupérer son export de données LinkedIn
  1. Sur linkedin.com, cliquer sur sa photo de profil (ou "Moi") en haut à droite, puis Paramètres et confidentialité.
  2. Dans le menu de gauche, ouvrir Confidentialité des données.
  3. Cliquer sur Obtenir une copie de vos données ("Get a copy of your data").
  4. Choisir Télécharger l'ensemble de vos données (pour être sûr d'avoir les expériences, formations, compétences et langues), puis valider.
  5. LinkedIn envoie un email avec un lien de téléchargement (quelques minutes, parfois jusqu'à 24h) vers un fichier .zip.
  6. Télécharger ce .zip et l'importer ci-dessous — inutile de le décompresser.

L'import ajoute au profil actif les expériences, formations, compétences et langues trouvées (sans supprimer l'existant), et complète les champs de profil encore vides.

Ou importer via l'API LinkedIn (avec un access token)

Réservé aux membres localisés UE/EEE/Suisse sur leur profil LinkedIn (condition imposée par LinkedIn).

  1. Créer une app sur linkedin.com/developers/apps, rattachée obligatoirement à la page entreprise "Member Data Portability (Member) Default Company" (ne pas créer de nouvelle page).
  2. Dans l'onglet Products de l'app, demander l'accès à "Member Data Portability API (Member)" (accordé automatiquement après acceptation des CGU).
  3. Dans le portail développeur, menu Docs and tools → OAuth Token Tools, générer un token pour cette app avec le scope r_dma_portability_self_serve, et se connecter pour consentir.
  4. Coller ce token ci-dessous.

Le token n'est jamais enregistré côté serveur, il ne sert qu'à cette requête. Il expire au bout de 60 jours (à régénérer manuellement ensuite).
